Self-contained HTML viewer of used tire listings (205/55 R16, Kaunas region),
scraped from four Lithuanian classifieds and rendered into one offline-capable
PWA. Live at **https://gerimantas.github.io/padangos/**.

## Golden rules (the ones that bite)

- **Never edit `padangos.html` / `index.html` directly** — they are generated.
  Edit `template.html`, then `node build.js`.
- **Never hand-edit `.firecrawl/`** — scrape output + intermediate JSON,
  gitignored, regenerated by the pipeline.
- **Scraping costs firecrawl credits; parsing/building is free.** Use
  `./scripts/run-all.sh --build-only` for anything that isn't fetching new data.
- **Two seasons, never cross-contaminate.** `SEASON=winter|all-season` drives the
  parsers; each writes `*-<season>.json` with its own cache dir. Build reads both
  and stacks them as tabs. Re-parsing one season must never touch the other's
  files — if a count changes unexpectedly, a season-scoped file is stale.
- **Verify the viewer headless after any `template.html` change** — see the skill's
  `references/verify.md`. The load-bearing invariant: no horizontal scroll on a
  phone (`scrollWidth === clientWidth === 390`).
- **All files/code/comments in English.** (Chat may be Lithuanian.)

## PWA / deploy

- GitHub Pages serves the repo root on `main`. `build.js` emits both
  `padangos.html` and `index.html` (the install entry).
- After a data/UI change: `node build.js` → commit → `git push`. Pages redeploys
  in ~1 min.
- **Bump `CACHE` in `sw.js`** whenever the data or page changes, or installed
  phones keep serving the stale cached copy.
- QR to the live app: `padangos-qr.png` (root) + `qr.html` share page.

## Layout of the repo

- `template.html` — the viewer (all UI/CSS/JS). `build.js` inlines data + head.
- `parse*.js`, `merge.js` — the pipeline (see skill).
- `scripts/*.sh` — scrapers + `run-all.sh` orchestrator.
- `manifest.webmanifest`, `sw.js`, `pwa/` — PWA assets.
- `.claude/skills/padangos/` — the operational skill (source of truth for how-to).
